# 元素自走棋：装备文案与图标包 V3

## 1. 使用说明

- 本包包含18件装备的最终低粒子图标、属性文案和JS配置。
- 每名棋子最多装备3件；同名装备不可重复。
- **“约12金币”只用于内部平衡评价，不得在玩家界面显示价格或价值文字。**
- 装备的基础属性根据其主要使用者和核心效果设计，不强制每件装备拥有相同数量的属性。
- 图标为低粒子、暗色奇幻MOBA装备风格；单独图标均已裁成`512×512 PNG`。

## 3. 详细结算规则

### 秘法棱镜
- 可暴击：技能直接伤害、多段技能、引导伤害、领域伤害。
- 不可暴击：元素反应、固定伤害、装备伤害、召唤物伤害、自伤、治疗和护盾。
- 每段伤害、每个目标独立判定。

### 战意徽章
- 一次普通攻击最多获得1层。
- 一个完整技能最多获得1层；多段或范围命中不重复叠层。
- 元素反应、装备伤害和召唤物伤害不叠层。
- 层数持续到战斗结束。

### 巨人猎手
- 比较双方最终最大生命，不比较当前生命。
- 只提高普攻和技能伤害。

### 破盾之矛
- 在本次伤害开始结算时检查目标是否有护盾。
- 若有护盾，整次伤害均增伤，包括击破护盾后溢出至生命的部分。

### 处刑之刃
- 多段技能每一段重新检查目标当前生命比例。
- 暴击伤害从默认140%提高至170%。

### 饮血长刃
- 只按`damageResult.hpDamage`计算吸血。
- 不包括护盾吸收、过量伤害、反应、装备、召唤物和自伤。
- 治疗受重伤影响。

### 裁决徽记
- 只由技能造成的有效伤害触发。
- 普攻、元素反应、装备伤害、反伤和附着用1点伤害不触发。
- 重伤不叠加，重复施加刷新持续时间；不同重伤取最高值。

### 回能指环
- 每次普通攻击最多触发一次；范围普攻命中多人也只触发一次。
- 零有效伤害、免疫、召唤物、反伤和装备伤害不触发。

### 时序弓弦
- 控制、移动和施法不停止计时。
- 层数持续至战斗结束。

### 狂战护腕
- 生命恢复到50%及以上时，额外攻速立即移除。

### 追猎羽饰
- 技能中断不触发。
- 重复触发只刷新持续时间，不叠加数值。

### 坚壁重铠
- 降低普攻、技能、元素反应和敌方装备伤害。
- 不降低主动生命消耗、自伤、系统直接扣血和不可减免伤害。

### 守护之誓
- 先结算所有最大生命属性，再创建护盾。
- 与技能护盾分来源记录，不直接覆盖。
- 只统计实际吸收量，未消耗的过期护盾不计入统计。

### 再生坠饰
- 第一次治疗发生在战斗开始2秒。
- 治疗护盾强度会提高本装备自身治疗，也会提高装备者其他治疗和护盾。
- 满血时不显示治疗数字、不增加治疗统计，但计时正常重置。

### 急救吊坠
- 每场只触发一次；伤害结算后仍存活才触发，不能复活。
- 治疗受重伤影响。

### 荆棘胸甲
- 有效承伤=`hpDamage + shieldAbsorbed`。
- 反伤无元素、不暴击、不附着、不触发反应、吸血或再次反伤。

### 水银披风
- 常驻韧性降低眩晕、冰冻、击飞和强制无法行动的持续时间。
- 首次硬控免疫不包括重伤、减攻、减攻速、元素附着或嘲讽。

### 救赎灯盏
- 第一次触发在战斗开始7秒，此后每7秒一次。
- 主目标：装备者10%最终最大生命治疗；周围1格其他友军：5%。
- 目标按生命比例最低选择；同比例按当前生命更低，再按实例ID稳定排序。
- 全队满血则跳过本次，但计时重新开始。

## 4. 全局上限

```text
每名棋子最多3件装备
同名装备不可重复
最终攻速上限5.0
暴击率上限100%
韧性上限50%
装备技能增幅合计上限40%
装备增伤合计上限45%
装备减伤合计上限35%
治疗护盾强度合计上限50%
```
