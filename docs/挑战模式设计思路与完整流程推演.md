# 元素自走棋：挑战模式设计思路、关卡详情与完整流程推演

> 数据基准：当前开发版实装代码与本地同步后的 20 关默认阵容。本文不引用旧版挑战模式草案。

## 一、模式定位

挑战模式不是单场战斗的集合，而是一局完整的自走棋运营流程。玩家从固定资源出发，在连续 20 关中同时处理四类压力：

1. **即时战力**：当前阵容能否击败本关。
2. **长期经济**：是立即刷新、买牌，还是保留金币获取利息。
3. **人口与商店等级**：升级会减少眼前可用金币，但能增加上阵人数并开放高费棋子。
4. **阵容适应**：敌方元素、站位、装备与主力会不断变化，玩家不能只用一种站位通关。

常规流程由三个阶段组成，每阶段 6 关；随后是 EX-1、EX-2 两场极限挑战。每阶段的第 5 关为奖励关，第 6 关为 Boss 关。

## 二、当前实装的资源规则

### 2.1 开局资源

| 资源 | 数量 |
|---|---:|
| 金币 | 30 |
| 等级 / 人口 | Lv3 / 3人口 |
| 经验 | 0 / 6 |
| 生命 | 3 |
| 免费刷新 | 3次 |
| 随机标准装备 | 2件 |
| 拆卸器 | 1个 |
| 重铸器 | 2个 |

商店首次生成和每回合未锁定时的自动换店不消耗金币，也不扣除手中的免费刷新次数。主动刷新优先使用免费刷新；免费次数耗尽后，每次刷新消耗 2 金币。

### 2.2 每场胜利结算

| 项目 | 当前规则 |
|---|---|
| 基础资金 | 3金币 |
| 利息 | 结算时每持有10金币获得1金币，最多10金币 |
| 连胜 | 第1—2胜各1金币；第3—5胜各3金币；第6胜起每胜5金币 |
| 经验 | 6经验 |
| 奖励关 | 额外10金币、1件随机装备 |
| Boss关 | 额外10金币、2件随机装备、3次免费刷新 |
| 通过1-6、2-6 | 额外获得拆卸器×2、重铸器×1 |
| 通过3-6并进入EX | 额外获得50金币 |

利息读取的是战斗结算瞬间的金币。战斗中可以买牌、卖牌，因此战斗中的消费同样会降低本回合利息。

### 2.3 失败与补偿

- 常规关失败：不推进关卡、连胜归零、失去1点生命。
- 第一次累计失败补偿：10金币、1件随机装备。
- 第二次累计失败补偿：10金币、1件随机装备、两张随机1星4费卡。
- 棋子奖励必须在备战席有足够空位时才能领取；未领取前不能开始下一场。
- 三次生命耗尽后，本次挑战存档结束。
- EX失败：恢复到开战前状态，不计算经济，不扣生命，可无限重试本关。

### 2.4 失败经济规则

普通关失败时只获得 **3金币基础资金**，不获得经验、利息、连胜金币、免费刷新或关卡胜利奖励。EX关失败会回滚到本场战斗前的状态，因此不会结算基础资金或利息。

## 六、模拟一局完整运营

### 6.1 模拟假设

- 全程胜利，不触发扣血补偿。
- 不锁商店，使用每回合免费自动换店。
- 战斗中不消费，保证表中利息稳定。
- “支出”包含买牌、主动刷新和购买经验；具体商店结果受随机数影响。
- 阵容示例只代表一条合理路线，不代表唯一答案或平均必得阵容。

| 3-6 / 8人口 | 2星四费主坦＋2星三费主C＋副C＋回复/护盾＋反应辅助 | 用八人高质量阵容对抗敌方九人，不盲目为了人口牺牲全部利息 |
| EX-1 / 9人口 | 加入钟离、胡桃、甘雨或八重神子等五费单卡 | 3-6的50金币用于升Lv9并补一张终局核心，不必强追三星 |
| EX-2 / 10人口 | 2星主坦、两名成型输出、钟离/心海等保护、完整元素共鸣 | 把剩余经济换成Lv10人口；最终局允许只剩少量金币，不再追求后续利息 |

### 6.4 这局运营说明了什么

1. **第一阶段允许存钱。** 敌方等价值从6增长到19，玩家用低费二星和基础装备即可建立优势。
2. **第二阶段迫使玩家开始花钱。** 装备数从4件增至8件，2-3开始全员二星，继续只存钱会失去战力。
3. **第三阶段考验阵容完整度。** 敌方不再只是更高星，而是有明确元素主题、领域装和多核输出。
4. **3-6是常规毕业线。** 玩家通常仍在Lv8，以八人口高质量阵容挑战九人Boss；通关即可保存挑战回顾。
5. **50金币决定EX节奏。** 它让玩家在EX前完成一次明显的终局跃迁，而不是把EX变成紧接3-6的纯数值墙。
6. **EX-2要求把经济转成战力。** 最后一关没有保留利息的长期价值，合理行为是升到Lv10并尽量完成二星高费核心。

## 七、关卡安排的设计结论

当前20关形成了清晰的教学—检验—兑现曲线：

- **1阶段教会玩家组成阵容**：前后排、基础升星、元素混搭。
- **2阶段教会玩家阅读敌方阵容**：装备、主坦、切后排、持续输出。
- **3阶段要求玩家解决完整体系**：每关用一种元素主题或辅助结构提出不同问题。
- **Boss关提供阶段句号**：更完整的阵容与更高奖励同时出现，建立完成阶段的实感。
- **EX让运营成果兑现**：不是简单追加两关，而是允许玩家用50金币完成终局升级，再接受九人口、十人口成型阵的检验。

从数值上看，敌方等价值从6增长到114、装备从1件增长到最高13件，人口从3增长到10；从玩法上看，则从单前排保护后排逐步发展为多核、共鸣、领域装备和终局保护链。两条成长线同时存在，才使挑战模式既有可读的难度上升，也保留阵容解题空间。
