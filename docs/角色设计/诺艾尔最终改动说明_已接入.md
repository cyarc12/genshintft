# 诺艾尔最终改动说明（已接入）

## 定稿结论

诺艾尔继续采用“当前双抗转护盾”的设计，护盾倍率调整为 **2 / 4 / 10**。

## 基础数据

- 生命值：800 / 1440 / 3600
- 攻击力：15 / 25 / 40
- 物理抗性：80 / 85 / 90
- 元素抗性：70 / 75 / 80
- 法力：20 / 90

## 被动

- 每名当前正在攻击诺艾尔的敌人，使物理抗性和元素抗性分别提高 10 / 12 / 15。
- 敌人切换目标或死亡后，对应层数延迟2秒移除。
- 护盾存在期间，被动层数冻结，不新增也不衰减。

## 技能

- 嘲讽当前目标所在格及周围六格内的敌人，持续5秒。
- 护盾持续5秒。
- 不造成伤害，不施加岩元素附着。
- 护盾值 =（当前物理抗性 + 当前元素抗性）× 2 / 4 / 10。
- 如受通用护盾强度影响，应在基础护盾公式计算完成后再乘对应加成。

## 二星校验

二星诺艾尔被4名敌人攻击：

- 物理抗性 = 85 + 4 × 12 = 133
- 元素抗性 = 75 + 4 × 12 = 123
- 护盾值 = (133 + 123) × 4 = 1024

## 接入验收

1. 0～5名敌人攻击时，护盾值随双抗线性变化。
2. 护盾期间新增攻击者不增加层数，离开目标也不减少层数。
3. 护盾结束后重新按当前攻击者数量结算。
4. 敌人切换目标后，层数延迟2秒移除。
5. 二星、4名攻击者时，装备护盾加成前为1024点。
6. 技能全程不出现伤害数字、岩附着图标或元素反应。
