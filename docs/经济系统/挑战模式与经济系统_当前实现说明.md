# 挑战模式与经济系统：当前实现说明

本文只记录当前游戏已接入的规则，不包含旧方案、原设计目标或未实现规划。

## 一、模式与关卡

- 挑战模式固定为18关，共3个阶段，每阶段6关。
- 顺序为：`1-1`至`1-6`、`2-1`至`2-6`、`3-1`至`3-6`。
- 每阶段的1至3关为普通发展关；第4关为压力关，但界面仍显示为普通关；第5关为奖励关；第6关为Boss关。
- `3-6`显示为最终Boss。
- 关卡不再提供简单、普通、困难选择。
- 敌方阵容使用18个固定关卡槽位。旧版16个槽位按原顺序迁移到前16关，新增的`3-5`与`3-6`默认留空。
- 关卡阵容配置与玩家挑战存档分开保存。
- 失败后停留在当前关卡并重新挑战，不跳关。
- 回合结束后，我方棋子恢复到本回合开战前记录的阵容和站位。

## 二、初始资源

- 金币：30。
- 等级：Lv3，经验0。
- 人口上限：3。
- 生命：3颗心。
- 连胜：0。
- 免费刷新：3次。
- 随机普通装备：2件。
- 重铸器：2个。
- 拆卸器：1个。

## 三、等级、经验与人口

- 只有胜利才获得6点经验，失败不获得经验。
- 购买经验消耗4金币并获得4点经验。
- 最高等级为Lv9。
- 人口上限等于当前等级。

## 四、商店与卡池

- 商店每次展示5张卡，按照费用从低到高排列。
- 购买后对应位置变为空位，其他卡不递补。
- 普通刷新消耗2金币；优先消耗累计的免费刷新次数。
- 每次胜利获得1次免费刷新。
- Boss关胜利额外获得3次免费刷新，因此Boss关合计获得4次。
- 回合结算并领取完全部奖励后，未锁定的商店自动刷新。
- 锁定后保留当前卡牌。
- 商店卡牌只能点击购买，不支持长按抓取。
- 商店卡与玩家已有棋子同名时，卡牌顶部显示金色提示线。
- Lv5抽卡概率为：1费39%、2费35%、3费25%、4费1%、5费0%。
- 其他等级沿用当前项目已有概率。

|---|---:|

| 2费 | 18 |
| 3费 | 15 |

## 五、金币、利息与连胜

- 每回合结束固定获得5金币基础资金，无论胜负都会发放。
- 开战时锁定本回合利息：`min(floor(开战金币 / 10), 10)`。
- 只有胜利才发放已锁定利息。
- 开战后获得或花费的金币不改变本回合利息。
- 胜利后连胜数加1；失败后连胜归零。
- 连胜1至2场：获得1金币。
- 连胜3至5场：获得3金币。
- 连胜6场及以上：获得5金币。

## 六、胜利结算

普通关胜利：

- 基础资金+5。
- 经验+6。
- 发放开战时锁定的利息。
- 发放当前连胜金币。
- 免费刷新+1。

奖励关（每阶段第5关）胜利，在普通胜利奖励之外额外获得：

- 金币+10。
- 随机普通装备1件。

Boss关（每阶段第6关）胜利，在普通胜利奖励之外额外获得：

- 金币+15。
- 随机普通装备2件。
- 额外免费刷新3次。

进入第二阶段和第三阶段时，分别获得一次新阶段补给：

- 拆卸器2个。
- 重铸器1个。

## 七、失败与补偿

失败时：

- 基础资金+5。
- 生命-1。
- 失败次数+1。
- 连胜归零。
- 除固定5金币基础资金外，不获得经验、利息、连胜金币、免费刷新或关卡奖励。
- 保持当前关卡，等待重新挑战。

第一次失败补偿：

- 金币+10。
- 随机普通装备1件。

第二次失败补偿：

- 金币+10。
- 随机普通装备2件。
- 两张相互独立抽取的一星4费卡；允许同名，并从共享卡池扣除。

第三次失败：

- 挑战结束。
- 不发放失败补偿。

失败补偿在玩家点击确认后才发放。若备战席没有足够空位，奖励保持待领取状态，玩家可隐藏窗口、整理备战席后再打开领取。若共享卡池中的4费卡总量不足，系统会单独提示卡池库存不足，不会误报为备战席已满。奖励领取完毕前仍属于旧回合结算阶段，不能进入下一回合。

隐藏奖励窗口后，挑战装备栏下方会持续显示醒目的“领取待处理奖励”按钮。点击该按钮可以重新打开奖励页面；只有奖励领取成功后，该按钮才会消失。

## 八、棋子、合成与出售

- 购买的棋子进入蓝方备战席。
- 备战席已满时不能购买或领取棋子奖励。
- 三个同名同星棋子自动合成下一星级。
- 挑战模式中右键场上棋子会将其送回备战席，不出售。
- 出售方式为长按抓起蓝方棋子并拖入商店区域。
- 出售时归还共享卡池数量，棋子携带的装备返回挑战装备库存。

## 九、装备

- 挑战模式使用独立装备库存。
- 普通装备可拖给蓝方棋盘或备战席棋子。
- 每名棋子最多装备3件，不能重复装备同名物品。
- 拆卸器卸下目标棋子的全部装备并放回库存。
- 重铸器将目标棋子的普通装备随机替换为其他普通装备。
- 拆卸器与重铸器都是一次性消耗品。
- 战斗中只能查看装备，不能穿戴、拆卸或重铸。

## 十、存档与兼容

- 当前玩家挑战存档版本为V3。
- 旧版12关挑战进度不继续沿用，开始挑战时创建新进度。
- 旧版16个关卡阵容槽位会迁移到新版18关槽位的前16格。
- 待领取失败补偿、阵容、商店、卡池、金币、经验、生命、连胜和免费刷新均写入挑战存档。

## 十一、完整流程校验

- 连续赢完18关的连胜金币合计为76。
- 不计算利息时，开局金币、18回合基础资金、奖励关、Boss关和连胜固定金币合计为271。
- 完成18关累计获得免费刷新30次。
- 开局与关卡胜利累计获得普通装备11件。
