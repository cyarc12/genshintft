# 元素自走棋当前实装内容索引

本页只记录当前游戏实际加载的内容规模和入口，避免历史资料与实装混淆。游戏唯一入口为根目录 `index.html`。

## 正式角色

当前共有 **34名正式角色**，另有1个测试木桩。

- 1费（9名）：迪卢克、妮露、莱依拉、宵宫、芙宁娜、优菈、芭芭拉、夏洛蒂、砂糖。
- 2费（8名）：申鹤、早柚、久岐忍、可莉、夜兰、神里绫华、克洛琳德、凝光。
- 3费（7名）：珊瑚宫心海、刻晴、阿蕾奇诺、达达利亚、那维莱特、枫原万叶、纳维亚。
- 4费（6名）：菲谢尔、琴、安柏、诺艾尔、雷电将军、玛薇卡。
- 5费（4名）：胡桃、八重神子、甘雨、钟离。

角色面板与技能最终值以 `index.html`、`balance-update-20260726.js` 和 `geo-characters.js` 共同加载后的结果为准。

## 装备与工具

当前共有 **27件普通装备**，另有 **装备拆卸器、装备重铸器** 两种工具。

装备名称、分类、属性和效果以 `equipment-config.js` 为唯一当前配置入口，战斗实现位于 `equipment-system.js`。

## 挑战模式

当前共有 **20关**：

- 第一阶段：1-1至1-6。
- 第二阶段：2-1至2-6。
- 第三阶段：3-1至3-6。
- EX阶段：EX-1、EX-2。

`default-pve-stages.json` 与 `pve-default-stages.js` 保存同一套20关默认阵容，前者用于交换和导出，后者供本地网页直接加载。两份数据必须保持一致。

挑战流程、经济、商店、奖励和存档实现位于 `pve-first-release.js`。普通关失败只发3金币基础资金，不发利息；EX失败回滚战前状态，不结算经济。
